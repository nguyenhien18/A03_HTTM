# Assignment 03 — Neural Network

Bài tập xây dựng và thử nghiệm các mô hình Neural Network trên ba bộ dữ liệu:

- **Diabetes:** dự đoán trên dữ liệu bệnh tiểu đường.
- **E-commerce:** phân tích và dự đoán trên dữ liệu thương mại điện tử.
- **House:** dự đoán giá nhà.

## Cấu trúc dự án

```
.
├── Data/                              # Dữ liệu đầu vào
├── models/                            # Các mô hình đã lưu
├── assignment03_diabetes_compact.ipynb
├── assignment03_ecommerce_compact.ipynb
├── assignment03_house_compact.ipynb
└── README.md
```

## Cách chạy

1. Cài đặt Python và Jupyter Notebook.
2. Mở terminal tại thư mục dự án.
3. Chạy lệnh:

```bash
jupyter notebook
```

4. Mở notebook tương ứng và chạy các cell theo thứ tự.

## Ghi chú

- Đảm bảo các file dữ liệu cần thiết nằm trong thư mục `Data/`.
- Các file tạm của Jupyter và Python được bỏ qua trong `.gitignore`.
